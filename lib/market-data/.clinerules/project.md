# Project Rules & Guidelines

## 1. Tech Stack & Environment
- Frontend/Backend: โครงสร้างโปรเจกต์เชื่อมต่อกับ GitHub, Supabase และ Deploy บน Render
- การทำงาน: พัฒนาและจัดการโค้ดผ่านมือถือและ AI Assistants

## 2. Investment Analysis Rules (Top-Down Analysis)
เมื่อมีการวิเคราะห์หุ้นหรือ ETF ให้ยึดลำดับและเงื่อนไขดังนี้:
1. **Weekly Chart:** หาแนวโน้มหลัก (Uptrend / Sideway / Downtrend) และเช็คว่าอยู่เหนือ MA40W หรือไม่
2. **Daily Chart:** หาจังหวะเข้าซื้อ (Pullback / Breakout) และตรวจสอบ Volume
3. **Decision Rules:**
   - ✅ **ลงทุนได้:** Weekly เป็น Uptrend + เหนือ MA40W + Daily อยู่ในจุด Pullback/Breakout + Volume สนับสนุน
   - ⚠️ **รอดู:** Weekly เป็น Sideway หรือ Daily ยังไม่ให้สัญญาณ
   - ❌ **หลีกเลี่ยง:** Weekly เป็น Downtrend หรือราคาต่ำกว่า MA40W และ MA200W

## 3. Output Format
รูปแบบการสรุปผลวิเคราะห์ทุกครั้งต้องประกอบด้วย:
- # สรุปภาพรวม Weekly (แนวโน้ม, ความแข็งแกร่ง, คะแนน)
- # วิเคราะห์ Daily (จุดเข้า, จุดสะสม, Stop Loss, Target 1, Target 2)
- # คำแนะนำ (ซื้อ / ทยอยสะสม / รอดู / หลีกเลี่ยง)
- # คะแนนความน่าสนใจ (x/100)
